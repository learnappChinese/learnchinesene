## 5. Bugs Found & Fixed in PR 11

1. **P0 — Runtime Type Cast Crash in DuoGamePathScreen (`lib/screen/duolingo/page/duo_game_path_screen.dart`):**
   - *Problem:* `targetLevel['id'] as num?)?.toInt()` passed an `int` to `levelId` parameter expecting `String`, causing compiler error. Furthermore, stage property extractions used fragile `as int` and `as String` casts, throwing `type 'Null' is not a subtype of type 'int' in type cast` whenever optional database fields were null.
   - *Fix:* Converted `levelId` to string `(targetLevel['id'] ?? targetLevel['level_id'] ?? '').toString()` and replaced all raw casts with safe `(val as num?)?.toInt()` and `.toString()`. Added constructor DI `controller` with route-scoped disposal (`_ownsController`).
   - *Regression Test:* Created `test/screen/duolingo/duo_game_path_screen_test.dart` (2/2 passed).
2. **P1 — Hanzi Writing Unused Feedback Binding (`lib/screen/hanzi_writing/screens/hanzi_writing_screen.dart`):**
   - *Problem:* `_validationFeedback` was assigned in 6 state transition points but never read in the UI, while unused method `_getModeName` and unused field `_sessionStartedAt` caused analyzer warnings.
   - *Fix:* Connected `_statusMessage` getter to return `_validationFeedback`, giving users real-time stroke feedback, and removed unused symbols.
3. **P2 — Static Analysis Warnings Cleanup Across Codebase:**
   - Cleaned up unused `startPeriod` in `lib/core/learning/data/learning_history_repository.dart`.
   - Cleaned up unused import, `_activeClient`, `dataPoints`, and unnecessary casts in `lib/core/learning/service/learning_mastery_service.dart`.
   - Cleaned up unused enum values and `_imagesLoaded` in `lib/screen/dragon_panda/screens/boss_battle/boss_battle_gameplay_screen.dart`.
   - Formatted all 336 files across `lib` and `test` with `dart format`.
