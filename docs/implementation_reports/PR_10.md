# PR 10 — Unified Chinese Fantasy Design System, Accessibility & UX Polish

## 1. Overview
- **PR:** PR 10
- **Branch:** `feature/pr10-design-system-ux`
- **Target Branch:** `hieu`
- **Key Objectives:**
  - **Canonical Chinese Fantasy Tokens & Theme Unification:** Consolidated all color definitions into `lib/core/theme/app_colors.dart` using authoritative adventure tokens (`jade`, `jadeGreen`, `imperialGold`, `crimson`, `parchment`, `cream`, `textDark`, `textMuted`, `ink`, `jadeGradient`, `crimsonGradient`, `orangeGoldGradient`). Re-exported `AppColors` from `lib/screen/dragon_panda/theme/app_colors.dart` to eliminate divergent palettes.
  - **Transparent System UI Overlays:** Configured `SystemUiOverlayStyle` in both `AppTheme.light` and `AppTheme.dark` `AppBarTheme` to enforce edge-to-edge transparent status bars with appropriate icon brightness (no abrupt black bar screen transitions).
  - **Reduced Motion & Accessible Animations:** Respect `MediaQuery.disableAnimations` in interactive animated widgets. `PandaCompanion` pauses its floating loop animation, and `FlashcardsScreen` snaps card flips instantly (0.0 / 1.0) without 3D rotation when reduced motion is requested.
  - **Actionable Locked Stage & Mission Sheet UX:** Transformed dead-end locked bottom sheets into actionable guideposts. `showLockedMissionSheet` now supports `actionLabel`, `actionIcon`, and `onViewRequired`. `UnitOverviewScreen` and `DuoGamePathScreen` compute prerequisite stage/mission context and offer direct "LÀM ẢI TRƯỚC" / "LÀM NHIỆM VỤ NÀY" action buttons that jump immediately to requirements.
  - **Controller Lifecycle & Route Scoping (P2-03):** Standardized controller lifecycle management across 15 screens. Screens accept optional constructor injection (`this.controller`) and manage owned disposal (`_ownsController = widget.controller == null && !Get.isRegistered<C>()`), eliminating state leaks and enabling clean widget test isolation.
  - **Elimination of Broad Silent Catches (P2-05):** Replaced silent `catch (_) {}` with structured `debugPrint` or typed exception logging across services, repositories, and controllers to prevent silent failures and ease diagnostics.
  - **Multi-Resolution Responsive Verification:** Verified all interactive flows without layout overflows across 320x568, 360x640, 393x852, and 440x956 viewports.
