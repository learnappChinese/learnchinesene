# PR 08 — Personalized Home, Smart Next Action & Learning Recommendation

## 1. Overview
- **PR:** PR 08
- **Branch:** `feature/pr08-personalized-home-recommendations`
- **Target Branch:** `hieu`
- **Key Objectives:**
  - **Single Authoritative Recommendation Contract:** Created typed `RecommendedNextAction` model and refactored `LearningRecommendationService` as the single source of truth for next actions across the application.
  - **Eliminated Duplicate Recommendation Logic:** Removed redundant next-action logic between `HomeJourneyRepository` and `LearningJourneyRepository.getNextAction()`. `LearningJourneyRepository.getNextAction()` now delegates directly to `LearningRecommendationService.recommend()`.
  - **Strict Deterministic 7-Tier Priority Order:**
    1. **Resume Active Session:** Outranks all suggestions; preserves challenge index, game ID, level ID, and progress provenance.
    2. **Next Unit CTA:** Recommended when user has completed the current unit (all missions completed and boss won); falls back to Explore when all curriculum units are complete.
    3. **Boss Ready CTA:** Recommended when the boss is available and unlocked on the server, outranking review and in-progress missions.
    4. **Overdue Review CTA:** Recommended when SRS review items are due (`totalDue > 0`), with `canBypass: true` to ensure the curriculum path is **never locked**.
    5. **In-Progress Mission CTA:** Recommended next unlocked mission along the server-verified path (`unit_learning_path_v2`), using honest state labels ('THỬ LẠI' for failed, 'TIẾP TỤC' for in-progress).
    6. **Weak-Skill Practice CTA:** Evidence-based recommendation targeting the lowest skill mastery score from `UnitMastery` when below the mastery threshold.
    7. **Explore CTA:** Encourages world map and section exploration when current content is completed or for new user onboarding.
  - **Server Truth & Zero Speculation:** Boss availability is strictly validated against server truth (`unit_learning_path_v2` and `LearningUnitViewModel`). Contradictory states never guess a Boss CTA.
  - **Zero Today/Lifetime XP Flipping:** When `todayXp == 0`, Home strictly displays `0` and never substitutes lifetime XP or totalExp.
  - **Partial Failure Resilience:** Failure of optional or individual slices (review summary, history activity, XP activity) preserves the last-known-valid Home journey snapshot and displays a non-intrusive offline/stale notice badge with retry support.
  - **New User Onboarding CTA (< 5 Min):** New users with zero prior activity receive a valid, immediate CTA for Unit 1, Mission 1 with an estimated time <= 5 minutes.

## 2. Key Architecture & File Changes

### A. Unified Recommendation Model & Service
- **New File:** `lib/core/learning/model/recommended_next_action.dart`
  - Defines `RecommendedActionType` (`resume`, `startMission`, `fightBoss`, `review`, `practiceWeakness`, `nextUnit`, `explore`).
  - Defines immutable `RecommendedNextAction` with fields: `type`, `actionType`, `destination`, `unitId`, `stageId`, `gameId`, `gameCode`, `levelId`, `sectionNumber`, `unitNumber`, `reasonCode`, `label`, `title`, `subtitle`, `description`, `estimatedMinutes`, `dataVersion`, `xpReward`, `currentIndex`, `currentTotal`, `rewardPreview`, `canBypass`, `metadata`.
  - Provides seamless backwards-compatibility converters: `toLearningRecommendation()` and `toLearningNextAction()`.
- **File:** `lib/core/learning/model/learning_recommendation.dart`
  - Enhanced with optional typed fields (`actionType`, `destination`, `unitId`, `stageId`, `reasonCode`, `dataVersion`) and `label` getter to maintain 100% backwards compatibility.
- **File:** `lib/core/learning/service/learning_recommendation_service.dart`
  - Implements the canonical 7-tier priority evaluation.
  - Accepts dependency-injected loaders (`pathLoader`, `activeSessionLoader`, `overdueCountLoader`, `journeyRepository`, `reviewRepository`, `progressRepository`) for deterministic testing.
  - Maps weak skill targets cleanly with technical keys for routing (`weak:speaking:unit_1`) and localized Vietnamese titles ("Củng cố Phát âm").

### B. Single Source of Truth & Repository Unification
- **File:** `lib/core/learning/data/learning_journey_repository.dart`
  - Refactored `getNextAction()` to delegate directly to `_recommendationService.recommend()` and map via `nextAction.toLearningNextAction()`.
  - Eliminated over 130 lines of duplicated query and priority branching code.
- **File:** `lib/screen/home/data/home_journey_repository.dart`
  - Injected `LearningRecommendationService.recommend()` output into `HomeJourney.nextAction` and `HomeJourney.recommendation`.
  - Populates `missionTitle` and `nextRewardXp` from the authoritative next action.
- **File:** `lib/screen/home/model/home_journey.dart`
  - Added `RecommendedNextAction? nextAction` field.

### C. Home Controller & Dashboard Resilience
- **File:** `lib/screen/home/home_screen.dart`
  - Purged deceptive XP fallback logic: `xp: controller.todayXp.value` is passed directly without flipping to `lifetimeXp` when 0.
  - Passes `errorMessage: controller.journeyError.value` to `HomeDashboard`.
  - Updated `_openCurrentJourney()` to route dynamically based on `nextAction.type` (Review -> `ReviewScreen`, Next Unit -> `UnitOverviewScreen`, Explore -> `LearningSectionsScreen`).
- **File:** `lib/screen/home/widgets/home_dashboard.dart`
  - Added `_staleNotice()` banner when `errorMessage != null` to communicate offline/stale state without blanking the screen or journey card.
- **File:** `lib/screen/home/widgets/home_learning_sections.dart`
  - Dynamic button label derived from `journey?.nextAction?.label ?? journey?.recommendation?.cta ?? 'Tiếp tục'`.
