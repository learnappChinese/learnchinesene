# PR 05 — Production Security: Premium, IAP, Gemini AI & Supabase

## 1. Overview
- **PR:** PR 05
- **Branch:** `feature/pr05-security-iap-gemini`
- **Target Branch:** `hieu`
- **Key Objectives:**
  - Eliminate all hardcoded API keys (Gemini API key) and direct client calls to external LLM providers.
  - Implement server-side AI gateway via Supabase Edge Function (`gemini-ai-gateway`) with token auth, rate limiting, and quota enforcement.
  - Establish server-verified In-App Purchase & subscription entitlement (`app_user_entitlements`) with strict RLS and anti-replay fraud prevention.
  - Centralize entitlement decision-making in `PremiumAccessService` and decouple from client `SharedPreferences`.
  - Secure account switching so User A's premium cannot leak to Guest or User B.

## 2. Key Architecture & Changes

### A. Gemini AI Security
- **File:** `lib/core/config/app_config.dart`
  - Removed `geminiApiKey` and `geminiEndpoint`.
  - Configured `geminiGatewayFunction = 'gemini-ai-gateway'`.
- **File:** `supabase/functions/gemini-ai-gateway/index.ts`
  - Validates caller authentication via Supabase JWT.
  - Checks user entitlement (`app_user_entitlements`) for premium actions (`conversation_continuation`, `hsk_exam_analysis`).
  - Enforces per-user daily quota via `check_and_increment_ai_quota` RPC (Free: 20 req/day; Premium: 200 req/day).
  - Calls Gemini 1.5 Flash via server-to-server HTTPS using `GEMINI_API_KEY` stored in server environment.
  - Sanitizes response and validates JSON schema.
  - Returns typed HTTP errors (`401 authentication_required`, `403 premium_required`, `429 quota_exceeded`, `503 ai_temporarily_unavailable`).
- **File:** `lib/core/services/gemini_service.dart`
  - Forwards requests to Supabase Edge Function gateway.
  - Maps error responses to typed `AiGatewayException`.
- **File:** `lib/core/ai/model/ai_gateway_exception.dart`
  - Defines `AiGatewayErrorCode` and `AiGatewayException`.

### B. Premium Entitlement & In-App Purchase
- **Migration:** `supabase/migrations/20261011180000_secure_entitlements_and_ai_quotas.sql`
  - `app_user_entitlements`: authoritative store for user subscriptions.
  - `ai_usage_quotas`: tracks daily request count and token consumption.
  - Strict RLS: `SELECT` allowed only for owner (`auth.uid() = user_id`); direct `INSERT`/`UPDATE`/`DELETE` revoked from client roles (`authenticated`, `anon`).
  - `verify_app_store_purchase` (SECURITY DEFINER RPC): verifies transaction ownership, anti-replay fraud check across users, computes valid duration, and upserts entitlement.
  - `get_user_entitlement` (SECURITY DEFINER RPC): retrieves active entitlement for caller `auth.uid()`.
  - `check_and_increment_ai_quota` (SECURITY DEFINER RPC): enforces limits per tier.
- **Model:** `lib/core/entitlement/model/user_entitlement.dart`
  - Typed `UserEntitlement` and `EntitlementStatus`.
- **Repository:** `lib/core/entitlement/data/entitlement_repository.dart`
  - `SupabaseEntitlementRepository`: invokes `get_user_entitlement` and `verify_app_store_purchase`.
- **Service:** `lib/core/entitlement/service/premium_access_service.dart`
  - Single authoritative source for premium feature gates (`isLevelUnlocked`, `isFeatureUnlocked`).
  - Listens to `AuthController.currentUser` to ensure clean transitions during sign in, sign out, and account switching.
- **Controller & UI:**
  - Refactored `SubscriptionController` (`lib/screen/subscription/controller/subscription_controller.dart`) to verify store purchases server-side before activating premium.
  - Updated `SubscriptionPage` (`lib/screen/subscription/page/subscription_page.dart`) with active entitlement status banner, restore purchases button, and store terms/privacy notices.
