- Implementation summary:
  - Built comprehensive Authentication and Identity Lifecycle architecture:
    - `AppAuthUser`: model supporting Guest and Cloud identity without colliding with `supabase_flutter` internal types.
    - `AuthRepository` & `SupabaseAuthRepository`: handles Guest mode, email/password Sign In, Sign Up with display name, Password Reset, and Sign Out. Translates backend Auth exceptions into clear Vietnamese error messages. Never stores passwords in `SharedPreferences`.
    - `GuestProgressMigrationService`: safely reconciles local Guest attempts, pending activity submissions, Duo level progress (`merge_guest_duo_progress_v2`), and active sessions into Supabase Cloud. Uses stable event keys for idempotency (no duplicate XP). Only clears local guest cache after cloud confirmation; preserves local data on network failure for safe retry.
    - `AuthController`: single reactive coordinator managing `UserAuthStatus` (`initializing`, `guest`, `authenticating`, `authenticated`, `restoringSession`, `migratingGuestData`, `authError`, `signingOut`), observables, loading states, and automatic migration upon login/signup.
    - `LearningProgressSyncService`: integrated so account switching (User A -> Logout -> User B) invalidates all learning domains and re-reads fresh state from the server with zero data leakage.
  - UI Screens & Chinese Fantasy Adventure Theme:
    - `WelcomeScreen`: first-time onboarding with Panda companion avatar, explaining value proposition, offering "CHƠI THỬ NGAY (GUEST)" and "ĐĂNG NHẬP / TẠO TÀI KHOẢN".
    - `LoginScreen`: email/password login, password visibility toggle, forgot password link, switch to register, and continue as guest.
    - `RegisterScreen`: display name, email, password, confirm password validation, and auto-migration trigger.
    - `ForgotPasswordScreen`: recovery email form with friendly confirmation feedback.
    - `GuestSavePromptSheet`: unobtrusive bottom sheet for guest users to save progress after milestone or from profile.
    - `ProfileAchievements`: added live account status card showing Guest vs Cloud state, email, and Sign Out with confirmation dialog.
    - `SplashController`: routes first-time users to `WelcomeScreen` and returning/guest users to `HomeScreen`.
    - `MissionCompleteOverlay`: offers guest users a non-intrusive link to save progress to cloud after mission victory.
