# PR 06 — Curriculum, Adaptive Session Composer & Content Quality

## 1. Overview
- **PR:** PR 06
- **Branch:** `feature/pr06-curriculum-adaptive-session-composer`
- **Target Branch:** `hieu`
- **Key Objectives:**
  - Enforce strict unit-bounded learning: missions only draw verified challenges/content belonging strictly to the requested Unit/Level.
  - Eliminate deceptive fallback logic (removed `getRandomFlashcards` from the global SQLite database that previously served random out-of-unit challenges when a level had 0 content).
  - Solve the ID ambiguity between text-based Duo Unit IDs (`duo_unit_id`, e.g. `'unit_1_duo'`) and integer Lexicon Unit IDs (`lexicon_unit_id`, e.g. `1`) via `UnitBridgeResolver`.
  - Introduce `LearningSessionComposer`: separates challenge selection, question budget bounding (5–10 items), and provenance validation from UI runners.
  - Fix the Active Session re-shuffling bug: store and restore `challenge_ids` sequence in `duo_active_sessions` (Cloud/Local) to guarantee deterministic resumption order without question scrambling.
  - Provide graceful `ContentUnavailableException` UI states (Panda companion + clear message + retry/back) instead of fabricating fake content when a unit's data is incomplete.

## 2. Key Architecture & Changes

### A. Provenance & Bridge Models
- **File:** `lib/core/learning/model/learning_source_context.dart`
  - Canonical provenance context containing `courseId`, `sectionId`, `duoUnitId` (String), `lexiconUnitId` (int?), `levelId`, `gameCode`, `mode`, `allowedChallengeIds`, and `metadata`.
  - Includes standard `LearningMode` constants (`duoMission`, `reviewSession`, `practice`, `boss`).
- **File:** `lib/core/learning/service/unit_bridge_resolver.dart`
  - Safely bridges text-based Duo Unit IDs and integer Lexicon Unit IDs without blind casting or integer parsing assumptions.
  - Supports explicit mappings, direct numeric strings, and prefixed unit formats (`unit_<N>`, `u_<N>`, `u<N>`, `chapter_<N>`).
  - Helper `buildBridgeContext(...)` builds authoritative source contexts.
- **File:** `lib/core/learning/model/composed_learning_session.dart`
  - `ComposedChallengeItem` and `ComposedLearningSession` represent strictly bounded and ordered challenge sequences.
  - Provides full serialization (`toSnapshot()`, `toJson()`, `fromJson()`) preserving exact order indices, score, combo, and resumption state.

### B. Adaptive Session Composer Service
- **File:** `lib/core/learning/service/learning_session_composer.dart`
  - Domain service responsible for querying unit challenges, capping question budget (default 8, minimum 3), and constructing sessions.
  - Enforces unit boundary: throws `ContentUnavailableException` if a mission has fewer than 3 challenges, preventing deceptive fallbacks.
  - Active session restoration: reconstructs the exact challenge order saved in `challenge_ids` without re-shuffling.
  - Testable design: supports injected `challengeFetcher` and `activeSessionGetter` callbacks for fast, deterministic unit testing.

### C. Runner Controller & Persistence Updates
- **File:** `lib/core/database/duo_db_helper.dart`
  - Updated `saveActiveSession` and `getActiveSession` to support optional `challengeIds` (persisted in SQLite `challenge_ids` JSON / text field and Supabase `duo_active_sessions.challenge_ids`).
- **File:** `lib/screen/duolingo/controller/duo_game_repository.dart`
  - Removed out-of-unit random flashcard fallbacks from `getLearnWordsQuestions` and `getWordConnectQuestions`.
- **File:** `lib/screen/duolingo/controller/duo_game_runner_controller.dart`
  - Integrated `LearningSessionComposer` and `LearningSourceContext`.
  - Replaces ad-hoc database queries with `_sessionComposer.composeSession(...)`.
  - Catches `ContentUnavailableException` and sets user-friendly error message.
  - Saves ordered `challengeIds` when saving active session progress.
- **File:** `lib/screen/duolingo/page/duo_game_runner_screen.dart`
  - Passes explicit `unitId: 'unit_${widget.chapterNumber}'` to controller.
- **File:** `lib/di.dart`
  - Registered `UnitBridgeResolver` and `LearningSessionComposer` with GetX DI container.
