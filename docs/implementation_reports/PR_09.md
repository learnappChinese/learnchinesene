# PR 09 — AI Learning Quality, HSK Quiz/Exam & Unified Learning Outcomes

## 1. Overview
- **PR:** PR 09
- **Branch:** `feature/pr09-hsk-exam-quiz-engine`
- **Target Branch:** `hieu`
- **Key Objectives:**
  - **Ground HSK Quiz in Real Curriculum:** Completely removed LLM hallucinated words from quiz generation. Built `HskQuizRepository` and `CloudHskQuizRepository` querying authoritative database words (`lexicon_words` by `hsk_level_id`) with curated `HskSeedVocabulary` fallback for offline resilience. All questions attach canonical provenance (`source_word_id`, `word_id`, `hsk_level`, and pedagogical explanation).
  - **HSK Exam Durability & Score Persistence:** Guaranteed that raw deterministic objective scores are persisted to history (`HistoryService`) **immediately upon exam submission**, before requesting Gemini AI analysis. If the AI analysis times out, throws `AiGatewayException`, or encounters network errors, the user's score and answer review remain 100% intact. Added `retryAnalysis()` allowing users to retry AI performance feedback without resubmitting or duplicating history records.
  - **Truthful Two-History System Separation:** Explicitly separated and labeled official learning progress ("Lịch sử học tập" from `LearningHistoryRepository` / `learning_attempts` / `learning_xp_events`) and local AI utility history ("Lịch sử công cụ AI" from `HistoryService` / `history_logs.json`). Added clear tab navigation and ensured local AI clearing never modifies or deletes official learning ledger records.
  - **Centralized Text-To-Speech (TTS):** Created centralized `TtsService` managing audio focus, sequencing, Chinese locale `zh-CN`, and speech rate. Eliminated ad-hoc `FlutterTts()` instantiations across `HskQuizScreen`, `HskExamController`, `DictionaryScreen`, `ConversationsController`, and `LessonsController`.
  - **Zero Unmetered Stage Unlocks:** HSK practice quizzes and freeform AI activities record dedicated practice history items and do not grant unearned curriculum stage unlocks or bypass learning activity policies.

## 2. Key Architecture & File Changes

### A. Centralized Audio & TTS Architecture
- **New File:** `lib/core/services/tts_service.dart`
  - Encapsulates `FlutterTts` with lazy configuration (`zh-CN`, adjustable speech rate).
  - Enforces stop-before-speak sequencing to prevent overlapping audio.
  - Handles platform channel exceptions gracefully without unhandled crashes.
- **File:** `lib/di.dart`
  - Registered `TtsService` in dependency injection container via `Get.lazyPut(() => TtsService(), fenix: true)`.

### B. Grounded HSK Quiz Engine
- **New File:** `lib/screen/hsk_quiz/data/hsk_quiz_repository.dart`
  - Defines `HskQuizRepository` interface.
  - Implements `CloudHskQuizRepository` querying `lexicon_words` filtered by `hsk_level_id`.
  - Implements `HskSeedVocabulary` containing curated standard curriculum vocabulary for HSK levels 1 to 6 (16 words each) with full provenance (`source_word_id`, `hanzi`, `pinyin`, `meaning_vi`, `hsk_level`).
- **File:** `lib/screen/hsk_quiz/domain/hsk_quiz_question_generator.dart`
  - Refactored to generate questions strictly from the curriculum pool.
  - Produces 4 distinct options per question, ensuring the correct answer is always included and distractors are unique non-matching curriculum words.
  - Attaches canonical metadata: `source_word_id`, `word_id`, `hsk_level`, and `explanation`.
- **File:** `lib/screen/hsk_quiz/controller/hsk_quiz_controller.dart`
  - Uses `HskQuizRepository` instead of direct LLM queries.
  - Records practice attempt into `HistoryService` with type `'Trắc nghiệm HSK'` and mode `'practice'`, preserving curriculum path integrity.
- **File:** `lib/screen/hsk_quiz/hsk_quiz_screen.dart`
  - Uses `CloudHskQuizRepository` and centralized `TtsService`.

### C. HSK Exam Durability & Analysis Recovery
- **File:** `lib/screen/hsk_exam/controller/hsk_exam_controller.dart`
  - Injects `TtsService` and eliminates direct `FlutterTts` instance.
  - Calculates deterministic objective score from verified correct answers.
  - Persists raw exam attempt immediately into `HistoryService` before initiating Gemini analysis.
  - Introduces `analysisError` observable for graceful error capture.
  - Provides `retryAnalysis()` which queries AI feedback for the active submitted attempt and updates the existing history record without duplicate attempts.
- **File:** `lib/screen/hsk_exam/widget/hsk_exam_content.dart`
  - Updated `HskExamResult` with `analysisError` notice and "Thử lại phân tích AI" retry button.
- **File:** `lib/screen/hsk_exam/hsk_exam_screen.dart`
  - Passes `analysisError` and `onRetryAnalysis` callbacks to `HskExamResult`.

### D. Truthful Two-History System
- **File:** `lib/core/services/history_service.dart`
  - Added `updateHistoryContent(String id, Map<String, dynamic> extraContent)` to allow updating existing attempts with AI analysis notes without duplication.
- **File:** `lib/screen/history/controller/history_controller.dart`
  - Injects both `LearningHistoryRepository` (official server progress) and `HistoryService` (local AI utility history).
  - Exposes `selectedTab` (0: Lịch sử học tập, 1: Lịch sử công cụ AI).
  - `clearAiHistory()` clears only AI utility history, explicitly preserving official learning history.
- **File:** `lib/screen/history/widget/history_content.dart`
  - Added `LearningAttemptTile` with official verified badges, XP tags, stars, and formatted timestamps.
  - Updated `HistoryItemTile` with "AI Tiện ích" labels and subtitle notes.
- **File:** `lib/screen/history/history_screen.dart`
  - Implemented tab selector toggling between "Lịch sử học tập" and "Lịch sử công cụ AI".
  - Dedicated informative banners explaining official XP vs local AI utility boundaries.

### E. TTS Centralization in Other Screens
- **File:** `lib/screen/dictionary/dictionary_screen.dart`: Uses `TtsService`.
- **File:** `lib/screen/conversations/controller/conversations_controller.dart`: Uses `TtsService`.
- **File:** `lib/screen/lessons/controller/lessons_controller.dart`: Uses `TtsService`.
