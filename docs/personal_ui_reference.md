# Personal tab reference implementation

`lib/screen/home/widgets/home_personal_tab.dart` renders the Personal tab using the supplied screenshot as visual reference, with the System Settings card removed as requested. The remaining three actions open the existing GetX routes for Profile, Premium subscriptions and the Vietnamese/Chinese dictionary.

The Personal tab uses `TabHeader`, the original `shared_landscape.png`, and the existing panda bottom navigation. Header insets, 16-unit card margins, 4-unit spacing below the header, 8-unit card gaps, 128-unit minimum card height, 24-unit corners, and 4-unit white borders match the Learning, Games and Progress tabs. `HomeIllustratedCard` is shared with Progress and preserves live Flutter text and full-card tap targets. The header handles the top safe inset and the scroll view reserves space for the floating navigation.

## Artwork

All action-card text across Learning, Games, Progress and Personal is rendered by `TabCardText`: titles use 18.sp, weight 900 and line height 1.1; descriptions use 15.sp, weight 600 and line height 1.3, separated by 5.w. Per-card colors remain tied to their artwork. Titles scale down to fit and descriptions wrap fully.

Generated with the built-in `image_gen` tool from the supplied reference and saved in the project:

- `assets/images/backgrounds/personal_profile.png`: panda, profile card, crown and a pink landscape.
- `assets/images/backgrounds/personal_premium.png`: gold VIP crown badge and a warm golden landscape.
- `assets/images/backgrounds/personal_dictionary.png`: red dictionary, Vietnamese and Chinese flashcards, and a peach landscape. The final edit removes the extra panda to match the reference subjects; the unused draft has been removed from the asset bundle.

The existing asset directory registration in `pubspec.yaml` includes these files.

## Preview and validation

`docs/personal_ui_preview.png` is rendered at 440 × 956 logical pixels at 2× resolution. Local Arial is used for the preview; native device typography can differ. Device status indicators and the home indicator are supplied by the operating system.

`home_personal_tab_test.dart` covers four viewport sizes, safe inset handling, absence of System Settings, three working card arrows, bottom navigation and readable descriptions at 1.5× text scaling. `tab_header_alignment_test.dart` compares the header, first-card position, horizontal margins and card spacing across all four tabs. The home integration test checks switching to Personal and returning Home.
