# PR 07 — Review, Hanzi, Speaking Context & SRS Quality

## 1. Overview
- **PR:** PR 07
- **Branch:** `feature/pr07-review-hanzi-speaking-context`
- **Target Branch:** `hieu`
- **Key Objectives:**
  - Unify cross-skill learning contexts using canonical `LearningSourceContext` from PR 06 across Review, Speaking, Hanzi, and Unit Overview.
  - Eliminate deceptive scoring & fabricated metrics: removed artificial multipliers (`score * 0.94`, `score * 0.92`, `score * 0.98`) from `SpeakingResultCard`. Metrics now honestly reflect Speech-to-Text transcript matching ("Độ khớp từ" and "Nhận dạng") rather than pretending to measure acoustic Chinese tones.
  - Fix Spaced Repetition (SRS) boundary calculation in `SupabaseReviewRepository`: corrected flawed `!mastered || ...` logic that previously caused future-scheduled words to appear due immediately. Correctly enforces `!mastered && (wrong > 0 || nextReview == null || !nextReview.isAfter(now))`.
  - Fix audio concurrency: `SpeakingController.start()` immediately stops ongoing TTS/audio playback (`await audioService.stop()`) before opening the device microphone.
  - Ensure curriculum vs. practice isolation: free Hanzi or Speaking practice sessions carry `LearningMode.practice` and do not falsely complete Unit curriculum stages. Curriculum stages pass canonical `duoUnitId` and `levelId`.
  - Reactive Review Hub: child routes (quiz, word detail, speaking, hanzi) reload the Review Hub upon returning (`?.then((_) => loadInitialData())`). When loading fails, displays a truthful error state with a retry button instead of a deceptive 0-items summary card.
  - Wire `ProgressService.markLearned` and `submitAnswer` to `LearningProgressSyncService.syncAfterLexiconChange()` to invalidate cached review/journey state across tabs.

## 2. Key Architecture & Changes

### A. Truthful Speaking Metrics & Audio Concurrency
- **File:** `lib/core/services/audio_service.dart`
  - Added public `stop()` method to stop ongoing audio/TTS playback.
- **File:** `lib/screen/speaking/widget/speaking_cards.dart`
  - Completely purged fake tone & fluency multipliers (`0.94`, `0.92`, `0.98`).
  - Replaced badges with honest STT matching metrics: "Độ khớp từ", "Nhận dạng", "Mức độ".
- **File:** `lib/screen/speaking/controller/speaking_controller.dart`
  - Calls `await audioService.stop()` prior to initializing microphone.
  - Accepts `sourceContext` and isolates reward submissions: passes `rewardUnitId` and `rewardLevelId` only when `sourceContext.isCurriculum == true`.
  - Supports dependency injection (`rewardService`, `speechService`, `audioService`, `permissionChecker`) for automated headless unit testing.

### B. Unit Stage Provenance & Hanzi Journey
- **File:** `lib/screen/unit_overview/page/unit_overview_screen.dart`
  - Updated `LearningStageActivityType.hanzi` and `LearningStageActivityType.speaking` to construct typed `LearningSourceContext` (`courseId: 'duo_chinese'`, `duoUnitId: 'unit_${chapter.chapterNumber}'`, `levelId: targetLevelId`, `mode: LearningMode.duoMission`).
  - Passes `firstCharId` and `sourceContext` directly to `HanziWritingScreen` and `SpeakingScreen`.
- **File:** `lib/screen/hanzi_writing/controller/hanzi_writing_controller.dart`
  - Updated `beginPractice` and `saveProgress` to accept optional `sourceContext`. Passes `rewardUnitId` and `rewardLevelId` to `_rewardService` only for verified curriculum sessions.
- **File:** `lib/screen/hanzi_writing/screens/hanzi_writing_screen.dart` & `hanzi_writing_home_screen.dart`
  - Accepts `sourceContext` and threads it to controller actions and screen transitions.

### C. SRS Due Boundaries & Reactive Review Hub
- **File:** `lib/screen/review/data/review_repository.dart`
  - Fixed SRS calculation: `final isDue = !mastered && (wrong > 0 || nextReview == null || !nextReview.isAfter(now));`. Words scheduled in the future with 0 wrong count are not marked due.
  - UTC timestamps used for consistent boundary comparison.
- **File:** `lib/screen/review/controller/review_controller.dart`
  - Added `?.then((_) => loadInitialData())` to all child navigation calls (`startCategoryReview`, `openItemPractice`).
- **File:** `lib/screen/review/review_screen.dart`
  - Replaced fallback to empty summary on load failure with a dedicated error UI and "Thử lại" (Retry) action.
- **File:** `lib/core/services/progress_service.dart`
  - Wired `markLearned` and `submitAnswer` to trigger `LearningProgressSyncService.syncAfterLexiconChange()`.
- **File:** `lib/screen/subscription/controller/subscription_controller.dart` & `page/subscription_page.dart`
  - Made `activeProductId` and `purchaseDate` reactive `Rx` variables synchronized with `_premiumAccess.currentEntitlement`.
